# 商城客服知识库

本目录保存客服 Agent 使用的初始 RAG 文档。当前内容面向本地开发和功能测试，依据商城现有接口、页面和业务状态整理；正式上线前应由运营、客服和法务共同审核。

## 文档元数据

当前版本不在 Markdown 正文中维护额外的 YAML。加载器根据目录和文件名生成元数据：

- `id`：去掉扩展名的相对路径。
- `title`：Markdown 文件名。
- `category`：文件所在的一级目录名。
- `source_path`：包含扩展名的中文相对路径。

## 内容边界

1. 这套文档描述商城当前可确认的通用流程，不承诺具体配送时效、退款到账时间或无条件售后结果。
2. 商品是否可配送、运费和包邮条件以商品详情及结算页的实时结果为准。
3. 订单状态、物流、金额和用户地址属于实时数据，应通过 MCP 工具查询，不从 RAG 文档推断。
4. 售后申请能力尚未形成完整的用户端工具闭环，客服 Agent 应先解释处理路径，不得声称已经替用户提交申请。
5. 后续需要文档版本、启用状态和标签过滤时，再增加结构化元数据。
