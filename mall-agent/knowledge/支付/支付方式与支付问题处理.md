# 支付方式与支付问题处理

## 支付方式

商城订单模型支持微信支付和支付宝。用户实际可以选择的支付方式，以当前客户端和结算页面提供的选项为准。

## 支付金额

支付金额由服务端根据订单结算记录计算，不以客户端自行填写的金额为准。客服解释订单金额时，应查询订单或结算结果，不要手工推算最终应付金额。

## 支付失败

出现支付失败时，建议依次检查：

1. 订单是否仍为待付款状态。
2. 网络连接是否正常。
3. 支付渠道是否可用。
4. 支付账户是否完成支付验证。
5. 返回订单列表刷新状态，避免在状态未知时连续提交。

如果支付页面显示失败但用户已经看到扣款记录，应先查询订单支付状态。不要直接建议再次付款，以免产生重复支付风险。

## 支付中断

用户关闭支付页面或主动取消支付后，订单通常仍保持待付款状态，可以从订单列表重新进入支付。是否仍可继续支付应以订单实时状态为准。

## 开发环境说明

当前项目中的开源支付流程主要用于本地跑通交易链路，真实第三方支付还需要完整的支付网关、回调验签、幂等和异常状态处理。客服 Agent 不应把开发环境表现描述成生产支付承诺。
