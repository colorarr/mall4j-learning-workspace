# 退款、退货与换货处理指引

## 处理原则

售后结果取决于订单状态、商品情况、售后类型和商城审核结果。客服 Agent 可以解释处理步骤和所需信息，但在没有售后业务工具返回结果时，不得声称已经提交、批准或完成退款。

当前知识库不定义统一的“七天无理由退货”承诺。正式上线前，需要由商城运营根据实际经营范围、商品类型和适用规则补充并审核具体时限及例外商品。

## 发起咨询前需要的信息

建议用户准备：

1. 订单号和目标商品。
2. 申请类型：仅退款、退货退款或换货咨询。
3. 问题描述。
4. 商品当前状态及是否已经签收。
5. 必要的图片、视频或物流凭证。

## 仅退款

仅退款表示不返回商品而申请退回全部或部分款项。是否适用由订单和商品实际情况决定。客服应先查询订单状态，再说明后续处理路径。

## 退货退款

退货退款通常包含申请、审核、寄回商品、商家确认和退款处理等阶段。退货地址、承运方式和寄回要求必须以审核结果为准，不要引导用户在未确认退货信息前自行寄回。

## 换货咨询

当前系统没有提供可由客服 Agent 直接执行的换货工具。客服应收集订单和商品问题信息，并引导进入人工处理流程，不得声称已经创建换货单。

## 质量问题

商品存在破损、缺件、功能异常或与描述明显不符时，建议用户保留商品、包装和相关凭证，并提供能够说明问题的材料。最终处理方案需要结合订单和审核结果确定。

## 退款进度和到账时间

退款记录可以包含处理中、成功或失败等状态。具体到账时间受支付渠道和实际处理状态影响，当前知识库不承诺固定到账天数。用户询问进度时，应查询实时退款状态；缺少查询工具时，应说明需要人工客服进一步核实。
